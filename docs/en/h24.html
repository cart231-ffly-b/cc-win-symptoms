H24

Claude Code's Grep returns No files found for a */ glob when searching below the working folder

claude code grep no files found but file exists · claude code grep glob not matching

Symptom

Claude Code searches with Grep, gets No files found, and concludes the file does not exist, although it does. The search path was below the working folder and the glob used */.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\a\b\sub" | Out-Null
[IO.File]::WriteAllText("$d\a\b\sub\SKILL.md", "markerterm`n")
Push-Location $d
$found = @()
foreach ($g in '**/SKILL.md', '*/SKILL.md') {
    $out = "Use the Grep tool exactly once with pattern set to markerterm, path set to exactly $d\a\b , glob set to exactly $g , and output_mode files_with_matches. Use no other tools. Then stop." | claude -p --allowedTools Grep --output-format stream-json --verbose | Out-String
    $found += ($out -match 'Found 1 file')
}
Pop-Location
"glob **/SKILL.md found the file: $($found[0]); glob */SKILL.md found the file: $($found[1])"
if (-not $found[0]) { 'CANNOT CHECK (even **/SKILL.md found nothing: check that claude -p can use Grep)' } elseif (-not $found[1]) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

Grep matches the glob against the path relative to the working folder, not relative to the path argument (official issue #104991). With path a\b, sub\SKILL.md is matched as a/b/sub/SKILL.md, so a one-level */SKILL.md does not match. **/ matches at any depth.

Fix

Write globs with **/. Say so in CLAUDE.md, and have Claude search again without the glob when it gets No files found.

# CLAUDE.md
- Grep globs are matched relative to the working folder. Use **/ instead of */
- On No files found, search again without the glob
