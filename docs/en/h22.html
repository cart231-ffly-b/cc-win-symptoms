H22

Claude Code's Edit and Write silently strip trailing whitespace outside .md files (tabs-to-spaces just deletes the tabs)

claude code edit tabs to spaces deletes tabs · claude code trailing whitespace removed

Symptom

You ask Claude Code to turn tabs into spaces and the tabs are gone with no spaces in their place (a<TAB>b becomes ab), while the tool says the replacement was made. Files written with Write lose their trailing spaces too. .md files are not affected.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\case.txt", "a`tb`tc`n1`t2`t3`n")
Push-Location $d
"Use the Read tool on case.txt, then use the Edit tool once on case.txt with old_string set to exactly one TAB character, new_string set to exactly two space characters, and replace_all true. Use no other tools. Then stop." | claude -p --allowedTools "Read,Edit" | Out-Null
Pop-Location
$b = [IO.File]::ReadAllBytes("$d\case.txt")
"case.txt was 12 bytes with 4 tabs; asked to turn each tab into two spaces; now $($b.Length) bytes, tabs left: $(@($b | Where-Object { $_ -eq 9 }).Count)"
if ($b.Length -eq 12) { 'CANNOT CHECK (the Edit did not happen: check that claude -p can use Read and Edit)' } elseif ($b.Length -eq 8) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

Outside .md files, Edit and Write strip whitespace at the end of each line of the text they are given before writing (official issue #100296). A replacement made only of whitespace is all trailing, so it becomes empty and the replacement turns into a deletion.

Fix

Do whitespace-only replacements, and writes that must keep trailing spaces, with a script (PowerShell -replace or Python) instead of Edit or Write, then check the byte count or git diff. Say so in CLAUDE.md.

$t = [IO.File]::ReadAllText('C:/work/case.txt')
[IO.File]::WriteAllText('C:/work/case.txt', $t.Replace("`t", '  '))
