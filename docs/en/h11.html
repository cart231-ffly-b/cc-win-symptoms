H11

On Windows, a cd into %TEMP% in Claude Code's Bash tool is undone on the next call

claude code Shell cwd was reset · claude code cd temp reset windows

Symptom

You cd'd into a folder under %TEMP% (AppData\Local\Temp) in the Bash tool, but the next call is back in the start folder and prints Shell cwd was reset to .... A cd into a sibling folder outside Temp (AppData\Local\Microsoft, for example) sticks.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory "$d\sub" -Force | Out-Null
$u = $d -replace '\\', '/'
$p = 'Use the Bash tool exactly twice, one command per call. Call 1: cd "U/sub" && pwd > "U/p1.txt" . Call 2: pwd > "U/p2.txt" . Then stop.'.Replace('U', $u)
Push-Location $d
$p | claude -p --allowedTools Bash | Out-Null
Pop-Location
if (-not (Test-Path "$d\p1.txt") -or -not (Test-Path "$d\p2.txt")) { 'CANNOT CHECK (the Bash tool did not run both calls: check that it is available and allowed)' } else {
$p1 = (Get-Content "$d\p1.txt" -Raw).Trim(); $p2 = (Get-Content "$d\p2.txt" -Raw).Trim()
"inside %TEMP%: same call after cd sub -> $p1 ; next call -> $p2"
if (-not $p1.EndsWith('/sub')) { 'CANNOT CHECK (cd did not work even inside the same call)' } elseif (-not $p2.EndsWith('/sub')) { 'REPRODUCED' } else { 'NOT REPRODUCED' }
}

Why it happens

On Windows, Claude Code's Bash tool sends the shell back to the start folder when the working directory after a call is under %TEMP% (official issue #110213). Inside the same call the cd works, so the first call behaves and later calls silently run somewhere else.

Fix

Name the working folder in every call (use absolute paths, or put the cd and the command in the same call). If you keep a scratch folder under %TEMP%, always use its absolute path.

cd "C:/Users/me/AppData/Local/Temp/work" && ./run.sh   # cd and run in the same call
