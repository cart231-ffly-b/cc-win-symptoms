H21

If a hook's .ps1 file is missing, writes go through even with onFailure: block

onFailure block not blocking · claude code hook ps1 missing

Symptom

A hook that blocks writes, called as powershell.exe -File <script> with onFailure: block, stops blocking after the script is moved or renamed. No error.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\.claude" | Out-Null
$settings = @'
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "powershell.exe",
            "args": ["-NoProfile", "-ExecutionPolicy", "Bypass", "-File", "${CLAUDE_PROJECT_DIR}/.claude/hooks/missing-script.ps1"],
            "onFailure": "block",
            "timeout": 30
          }
        ]
      }
    ]
  }
}
'@
[IO.File]::WriteAllText("$d\.claude\settings.json", $settings)
Push-Location $d
'Use the Write tool once to create out.txt with the text hi. Do not retry. Then reply done.' | claude -p --allowedTools Write | Out-Null
Pop-Location
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$d\.claude\hooks\missing-script.ps1" 2>$null | Out-Null
$code = $LASTEXITCODE
$w = Test-Path "$d\out.txt"
"exit code of powershell -File <missing .ps1>: $code; out.txt written despite onFailure block: $w"
if ($w) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

When the .ps1 passed to -File does not exist, Windows PowerShell 5.1 exits with 0xFFFD0000 (-196608). Claude Code treats that as success, so onFailure: block does not apply (official issue #100891). A missing executable, a timeout or exit 1 do block, per the issue.

Fix

Check inside the hook command that the script exists and exit 1 if not. End with exit $LASTEXITCODE so a deny (exit 2) from the script still comes back as 2.

"command": "powershell.exe",
"args": ["-NoProfile", "-ExecutionPolicy", "Bypass", "-Command", "$s = 'C:/hooks/guard.ps1'; if (-not (Test-Path -LiteralPath $s -PathType Leaf)) { exit 1 }; $global:LASTEXITCODE = 0; & $s; if (-not $?) { if ($LASTEXITCODE) { exit $LASTEXITCODE } else { exit 1 } }; exit $LASTEXITCODE"],
"onFailure": "block"
