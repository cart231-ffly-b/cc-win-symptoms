T10

$variables in a powershell -Command one-liner vanish before it runs

Symptom

powershell -Command "foreach ($i in 1..2) { $i }" fails with a syntax error. The code is fine; the child PowerShell received foreach ( in 1..2).

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
powershell -NoProfile -Command "foreach ($i in 1..2) { $i }"; $e = $LASTEXITCODE
"exit=$e"
if ($e -ne 0) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

Inside double quotes the calling PowerShell expands $i first (to nothing) and passes the result to the child.

Fix

Put the logic in a .ps1 and run it with -File. For a one-liner, use single quotes.

powershell -NoProfile -File .\job.ps1
powershell -NoProfile -Command 'foreach ($i in 1..2) { $i }'
