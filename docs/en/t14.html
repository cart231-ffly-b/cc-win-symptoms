T14

claude -p --allowedTools swallows the prompt after it

Input must be provided either through stdin or as a prompt argument · claude -p allowedTools prompt ignored

Symptom

claude -p --allowedTools Read "summarize this" stops with "Input must be provided either through stdin or as a prompt argument", although the prompt is right there.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$o = claude -p --allowedTools Read 'say hi' 2>&1 | Out-String
($o.Trim() -split "`n")[0]
if ($o -match 'Input must be provided') { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

--allowedTools and --add-dir take any number of values. The prompt placed after them is taken as one more tool name.

Fix

Send the prompt on stdin instead of as a positional argument.

'Summarize README.md' | claude -p --allowedTools Read
