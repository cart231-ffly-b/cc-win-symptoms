H19

Start Claude Code under a junction and the working folder is silently replaced by the real path (hooks too)

claude code junction path · claude code cwd resolved real path

Symptom

You started Claude Code in a folder under a junction made with mklink /J, but the working folder Claude reports, and the cwd and file_path your hooks receive, are the real path behind the junction. A hook whose allowed paths use the launch spelling no longer matches.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$real = Join-Path $d 'real'
$link = Join-Path $d 'link'
New-Item -ItemType Directory -Force "$real\repo" | Out-Null
cmd /c mklink /J "$link" "$real" | Out-Null
git -C "$real\repo" init -q 2>$null
if (-not (Test-Path "$link\repo")) { 'CANNOT CHECK (could not create the junction with mklink /J)' } else {
Push-Location "$link\repo"
$init = 'reply ok' | claude -p --model haiku --output-format stream-json --verbose --max-turns 1 | Where-Object { $_ -match '"subtype":"init"' } | Select-Object -First 1
Pop-Location
$cwd = [regex]::Match([string]$init, '"cwd":"([^"]+)"').Groups[1].Value.Replace('\\', '\')
"launched in: $link\repo"
"init cwd   : $cwd"
if (-not $cwd) { 'CANNOT CHECK (no init line from claude -p: check that claude -p works and is logged in)' } elseif ($cwd -like '*\real\repo') { 'REPRODUCED' } else { 'NOT REPRODUCED' }
}

Why it happens

Claude Code follows the junction in the starting folder and uses the real path as its working folder (official issue #106304; per the issue, 2.1.312 and earlier kept the launch spelling). The transcript folder is named after the real path too.

Fix

In hooks, resolve both sides to the real path before comparing (os.path.realpath in Python), and write allowed paths with the real path.

import os
ok = os.path.normcase(os.path.realpath(target)).startswith(os.path.normcase(os.path.realpath(root)) + os.sep)
