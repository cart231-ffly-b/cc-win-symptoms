H16

On Windows, Claude Code's Edit and Write silently change the letter case of the file name

Symptom

A Config.txt that Claude Code edited is now called config.TXT or another spelling with different letter case. The content is correct, the tool only said it was updated, and git status on Windows shows just M.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\Sub" | Out-Null
[IO.File]::WriteAllText("$d\Sub\EditBack.txt", "fruit = APPLE`r`n")
Push-Location $d
"First use the Read tool on the file Sub/EditBack.txt in the current folder. Then use the Edit tool exactly once with file_path set to exactly this string, character for character: $d\sub\editback.TXT . Replace APPLE with ORANGE. Use no other tools. Then stop." | claude -p --allowedTools "Read,Edit" | Out-Null
Pop-Location
$name = (Get-ChildItem -LiteralPath "$d\Sub" | ForEach-Object Name) -join ', '
$body = (Get-Content -LiteralPath "$d\Sub\EditBack.txt" -Raw).Trim()
"file name after the Edit: $name; content: $body"
if ($body -notmatch 'ORANGE') { 'CANNOT CHECK (the Edit did not happen: check that claude -p can use Read and Edit)' } elseif ($name -ceq 'editback.TXT') { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

When the file_path given to Edit or Write differs in letter case from the real name, Claude Code changes the content and also renames the file to the spelling in file_path (official issue #100987). Ordinary writes such as PowerShell Set-Content keep the name. Git on Windows ignores case by default, so the rename does not show.

Fix

Have Claude check the real name with Glob or Read before Edit or Write and use that exact spelling in file_path; say so in CLAUDE.md. Before committing, run git -c core.ignorecase=false status --short and look for a D and ?? pair.

git -c core.ignorecase=false status --short
# a D Config.txt next to ?? config.TXT means the name changed
