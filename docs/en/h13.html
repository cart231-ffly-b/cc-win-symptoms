H13

claude -p --json-schema silently stops working with an --agent that restricts tools (still reports success)

claude -p json-schema structured_output missing · claude --json-schema --agent

Symptom

A script that reads the structured answer (structured_output) from claude -p --json-schema gets nothing when --agent is added. Exit code 0, subtype success, is_error false, no error.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\.claude\agents" | Out-Null
[IO.File]::WriteAllText("$d\.claude\agents\ro.md", "---`nname: ro`ndescription: read-only test agent`ntools: Read`n---`nYou answer questions briefly.`n")
$schema = '{\"type\":\"object\",\"properties\":{\"answer\":{\"type\":\"string\"}},\"required\":[\"answer\"]}'
$q = 'What is 2+2? Reply with the answer.'
Push-Location $d
$a = $q | claude -p --model haiku --json-schema $schema --output-format json | Out-String
$b = $q | claude -p --model haiku --json-schema $schema --agent ro --output-format json | Out-String
Pop-Location
$ha = $a -match '"structured_output"'; $hb = $b -match '"structured_output"'; $ok = $b -match '"subtype":"success"'
"without --agent: structured_output=$ha; with --agent ro: structured_output=$hb, subtype success=$ok"
if (-not $ha) { 'CANNOT CHECK (even without --agent there was no structured_output: check that claude -p works and is logged in)' } elseif ((-not $hb) -and $ok) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

The --json-schema answer comes back through a tool named StructuredOutput. When the agent's tools: allowlist restricts tools, that tool is removed too, and Claude answers in plain text (official issue #109393).

Fix

When you pass --json-schema, treat a missing structured_output as a failure instead of trusting subtype or the exit code. Do not use an agent with a tools: allowlist in runs that need --json-schema.

$out = $prompt | claude -p --json-schema $schema --output-format json | Out-String
if ($LASTEXITCODE -ne 0 -or $out -notmatch '"structured_output"') { Write-Error 'no structured_output'; exit 1 }
