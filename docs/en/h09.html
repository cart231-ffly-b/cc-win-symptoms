H09

A Claude Code Bash command containing $$( is stopped by the dangerous-removal check

Symptom

A Bash tool call that deletes nothing is stopped by a check that says it may be a dangerous removal, and the command never runs. The command contains $$( (two dollar signs and a parenthesis). It is stopped even in bypassPermissions.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\p1.txt", 'Run exactly this Bash command and nothing else, then stop: echo ''a$$(b'' > x.txt')
[IO.File]::WriteAllText("$d\p2.txt", 'Run exactly this Bash command and nothing else, then stop: echo ''a$(b'' > y.txt')
Push-Location $d
Get-Content "$d\p2.txt" -Raw | claude -p --allowedTools Bash | Out-Null
Get-Content "$d\p1.txt" -Raw | claude -p --allowedTools Bash | Out-Null
Pop-Location
$y = Test-Path "$d\y.txt"; $x = Test-Path "$d\x.txt"
"echo with one dollar and a paren -> written=$y; echo with two dollars and a paren -> written=$x"
if (-not $y) { 'CANNOT CHECK (even the one-dollar command did not run: check that the Bash tool is available and allowed)' } elseif (-not $x) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

Before running a Bash command, Claude Code checks it for removals that could delete far too much. With $$( in it, Claude Code cannot be sure how the shell will read the command, so it treats it as a possible removal and stops it (official issue #108970). A single $( goes through.

Fix

Do not put text containing $$( in a command. Save it to a file with the Write tool first. If it must be in a command, escape the dollars: "a\$\$(b".

# save the text with the Write tool first
# if it must be in a command
echo "a\$\$(b"

echo 'a$(b' > y.txt ran; echo 'a$$(b' > x.txt was stopped by the removal check and x.txt was not created (2026-11-24, Claude Code 2.1.330)
