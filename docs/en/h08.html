H08

After claude -w -p exits, the git worktree stays locked and cannot be removed

Symptom

git worktree remove refuses a worktree made by claude -w with a locked working tree error, and git worktree prune leaves it too. claude -p exited with code 0. Every night run adds one more worktree.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
Push-Location $d
git init -q 2>$null
git -c user.name=t -c user.email=t@example.invalid commit -q --allow-empty -m init 2>$null
'Reply with the single word OK.' | claude -w e1 -p | Out-Null
$list = git worktree list --porcelain 2>$null | Out-String
Pop-Location
$wt = ([regex]::Matches($list, '(?m)^worktree ')).Count
$lock = $list -match 'locked claude'
"worktrees: $wt; lock line after claude -p ended: $lock"
($list -split "`n") | Where-Object { $_ -match '^locked' }
if ($wt -lt 2) { 'CANNOT CHECK (claude -w did not make a worktree: check that git is installed and claude -w works here)' } elseif ($lock) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

claude -w locks the worktree it makes with claude session e1 (pid ...). Run with -p, it does not remove that lock when it exits (official issue #111811). git neither removes nor prunes a locked worktree.

Fix

Before cleaning up, check that the pid on the locked line of git worktree list --porcelain is no longer running, and only then git worktree unlock and remove it. Do not unlock worktrees whose pid is still running, and check for uncommitted changes first.

git worktree list --porcelain
# for locked claude session ... (pid 1234)
Get-Process -Id 1234 -ErrorAction SilentlyContinue
# if nothing is shown
git worktree unlock <path>
git worktree remove <path>

with both claude -w e1 -p and claude -w -p, the worktree stayed locked to the pid of the exited process and git worktree remove refused it; unlocking only the locks of exited pids cleaned it up (2026-11-24, Claude Code 2.1.330)

Author's machine: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304, Japanese Windows (code page 932). Checked 2026-10-20 to 22.
