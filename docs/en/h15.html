H15

A partial Read of a subdirectory CLAUDE.md silently stops the rest of it from loading

Symptom

Claude ignores rules from a subdirectory CLAUDE.md while working in that folder. Earlier in the session it read a few lines of that CLAUDE.md. No error, no warning.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$res = @{}
foreach ($case in 'partial', 'plain') {
    $t = Join-Path $d $case
    New-Item -ItemType Directory -Force (Join-Path $t 'sub') | Out-Null
    $lines = 1..30 | ForEach-Object { "Rule $_`: keep files tidy." }
    $lines += 'MARKER: the code word for this folder is PELICAN.'
    [IO.File]::WriteAllText((Join-Path $t 'sub\CLAUDE.md'), ($lines -join "`n") + "`n")
    [IO.File]::WriteAllText((Join-Path $t 'sub\a.txt'), "hello`n")
    $ask = 'Without reading any file again, reply with the code word for the sub folder if any instructions you have contain one, otherwise reply UNKNOWN.'
    if ($case -eq 'partial') { $p = "Do exactly this: 1. Use the Read tool on sub/CLAUDE.md with offset 1 and limit 1. 2. Use the Read tool on sub/a.txt. 3. $ask" }
    else { $p = "Do exactly this: 1. Use the Read tool on sub/a.txt. 2. $ask" }
    Push-Location $t
    $out = $p | claude -p --allowedTools Read --output-format json | Out-String
    Pop-Location
    $res[$case] = $out -match 'PELICAN'
}
"knows the code word: after a partial Read first = $($res['partial']); without it = $($res['plain'])"
if (-not $res['plain']) { 'CANNOT CHECK (even without the partial Read the code word was not known: check that claude -p works and is logged in)' } elseif (-not $res['partial']) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

A subdirectory CLAUDE.md loads when Claude reads another file in that folder (official docs). If the session first read that CLAUDE.md with offset/limit, the full load never happens (official issue #111719).

Fix

Write in the root CLAUDE.md: read a subdirectory CLAUDE.md in full or not at all, never with offset or limit. Keep subdirectory CLAUDE.md files short with the important rules first.

# one line in the root CLAUDE.md
Read a subdirectory CLAUDE.md in full or not at all; never with offset or limit.

with the code word on the last line of a 31-line sub/CLAUDE.md, reading only sub/a.txt gave the code word (1 nested_memory entry in the transcript); reading the CLAUDE.md with offset 1, limit 1 first gave UNKNOWN (0 entries) (2026-11-25, Claude Code 2.1.330)

Author's machine: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304, Japanese Windows (code page 932). Checked 2026-10-20 to 22.
