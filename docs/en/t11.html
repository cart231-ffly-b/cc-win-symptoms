T11

Get-ChildItem -Include is ignored and every file comes back

Get-ChildItem -Include not working · -LiteralPath -Include ignored

Symptom

Get-ChildItem -LiteralPath $dir -Recurse -Include *.ps1 also returns .md and .json files, and whatever runs next touches them.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory "$d\inc" -Force | Out-Null
[IO.File]::WriteAllText("$d\inc\a.ps1", 'x'); [IO.File]::WriteAllText("$d\inc\b.md", 'x')
$n = @(Get-ChildItem -LiteralPath "$d\inc" -Recurse -File -Include *.ps1).Count
"matched $n files for -Include *.ps1 (expected 1)"
if ($n -eq 2) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

In Windows PowerShell 5.1, -Include is ignored when combined with -LiteralPath. No error.

Fix

Do not use -Include. Filter with Where-Object.

Get-ChildItem -LiteralPath $dir -Recurse -File |
  Where-Object { $_.Extension -eq '.ps1' }
