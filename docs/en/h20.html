Claude Code's PowerShell tool reports success as failure because of an earlier command's exit code

claude code powershell exit code 1 robocopy · claude code powershell tool reports failure but succeeded

Symptom

When Claude Code runs robocopy or similar in the PowerShell tool, the copy works but the call comes back as a failure with Exit code 1, and Claude retries or rewrites the command. The last statement succeeded.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine. It calls claude once, so it takes about a minute.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\s.json", '{"env":{"CLAUDE_CODE_USE_POWERSHELL_TOOL":"1"}}')
Push-Location $d
$out = "You must use the PowerShell tool (not Bash). Run exactly the PowerShell command in the next line once, then stop.`ncmd /c exit 3; 'done'" | claude -p --settings s.json --allowedTools PowerShell --output-format stream-json --verbose | Out-String
Pop-Location
$ran = $out -match 'done'
$err = $out -match '"is_error":true'
"the PowerShell tool ran the command: $ran; the call was reported as an error: $err"
if (-not $ran) { 'CANNOT CHECK (the PowerShell tool did not run: check that claude -p can use it)' } elseif ($err -and ($out -match 'Exit code 3')) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

In PowerShell an external program's exit code stays in $LASTEXITCODE. The PowerShell tool returns whatever $LASTEXITCODE holds at the end as the result of the whole call (official issue #97589). Plain powershell -Command or -File gives 0 for the same command. robocopy returns 1-7 on success.

Fix

After commands that return non-zero on success (robocopy, findstr, git diff --quiet), end with exit 0 and print the exit code as text. Real failures are then not flagged either, so have Claude read the exit= line.

robocopy src dst a.txt | Out-Null; $rc = $LASTEXITCODE; if ($rc) { "exit=$rc" }; exit 0
