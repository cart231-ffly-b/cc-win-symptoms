T03

With -File, a,b stays one string instead of an array

Symptom

You write -Path a,b expecting two paths. The script gets one path named a,b, then reports it missing or silently does nothing.

Check it in 30 seconds

Paste into Windows PowerShell 5.1. It only creates files under your %TEMP% folder. If the last line says REPRODUCED, it happens on your machine.

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\arr.ps1", 'param([string[]]$Path) "count=$($Path.Count) first=$($Path[0])"')
$o = powershell -NoProfile -ExecutionPolicy Bypass -File "$d\arr.ps1" -Path a,b
$o
if ($o -eq 'count=1 first=a,b') { 'REPRODUCED' } else { 'NOT REPRODUCED' }

Why it happens

Arguments given with -File are not parsed as PowerShell expressions. The comma makes an array only when you call the script from inside PowerShell.

Fix

Take one string and split it in the script with -split ','.

param([string]$Path)
foreach ($p in ($Path -split ',')) { $p.Trim() }
