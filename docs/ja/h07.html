H07

Claude Code で裏の Bash を TaskStop で止めても、& やパイプで動かしたプロセスが残る

症状

Claude Code に裏で動かさせた Bash を TaskStop で止め、claude -p も終わったのに、タスクマネージャーに sleep.exe や cat.exe、timeout.exe が残っている。tail -f や繰り返しだと残り続け、PC が重くなる。翌晩の実行とぶつかることもある。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\p.txt", "Do exactly these steps and nothing else:`n1. Use the Bash tool with run_in_background set to true to run exactly this command: sleep 123 & timeout 124 sleep 122 & sleep 125 | cat`n2. Use the TaskStop tool to stop that background task.`n3. Reply STOPPED and the task id.")
Push-Location $d
$o = Get-Content "$d\p.txt" -Raw | claude -p --allowedTools "Bash,TaskStop" | Out-String
Pop-Location
Start-Sleep -Seconds 3
$left = @(Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -match 'sleep(\.exe)?"?\s+12[235]\b' })
"claude said: $($o.Trim())"
"processes still running after claude -p ended: $($left.Count)"
$left | ForEach-Object { '  ' + $_.ProcessId + ' ' + $_.CommandLine }
'(leftover sleep processes end by themselves within about two minutes)'
if ($o -notmatch 'STOPPED') { 'CANNOT CHECK (claude did not report STOPPED: check that the Bash and TaskStop tools are available and allowed)' } elseif ($left.Count -gt 0) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Windows の Claude Code は、裏で動かした Bash を TaskStop で止めるとき、いちばん上の bash は止めるが、その中で & やパイプで動かしたプロセスまでは止めない（公式 issue #109388）。claude -p が終わっても、それらは Git の usr/bin の下のプロセスとして残る。

直し方

裏で動かすコマンドには timeout を付ける（timeout 20 sleep 301 のように、時間が来れば自分で消える）。ときどき下のコマンドで Git の usr/bin の下のプロセスを一覧にして、残りを探す。夜に無人で回すなら、終わったあとに残ったプロセスを見つけて次の回を止める仕組みを置く（本の6章 https://zenn.dev/kamijo_aoto/books/windows-claude-code-traps ）。

Get-CimInstance Win32_Process | Where-Object { $_.ExecutablePath -like '*\Git\usr\bin\*' } | Select-Object ProcessId, CommandLine

作者の PC での結果

claude -p で裏の Bash に sleep 123 & timeout 124 sleep 122 & sleep 125 | cat を動かして TaskStop で止めさせると、claude -p が終わった3秒後も sleep 3つ・timeout・cat の5つが残った。timeout 20 sleep 301 は TaskStop のあと2つ残り、20秒後に両方消えた（2026-11-24、Claude Code 2.1.330、Git for Windows）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。

ほかの症状

  • PowerShell の終了コードが、2 を返したのに 1 になる
  • -File で渡した2つ目の引数が、エラーなしで消える
  • -File で a,b と渡すと、配列にならず1つの文字列になる
  • パイプで渡した日本語が ? になる（claude -p・python・git）
  • python や claude の出力を変数に入れると文字化けする
  • 手で動かすと通る Python が、タスクスケジューラやリダイレクトのときだけ落ちる
  • PYTHONIOENCODING を設定したのに、python -I だと効かない
  • 日本語入りの .ps1 が、構文エラーになるか文字化けして動く
  • .cmd / .bat のコメントが、コマンドとして実行される
  • powershell -Command の1行に書いた $変数 が、呼ぶ前に消える
  • Get-ChildItem の -Include が効かず、全部のファイルが返る
  • "..." に書いた Markdown のバッククォートで、文字が消えて改行が入る
  • 書き込み中のログが 0 バイトに見える
  • claude -p --allowedTools の後ろに書いたプロンプトが飲み込まれる
  • Claude Code の PreToolUse フックが、時間切れになると書き込みを止めずに通す
  • PowerShell のフックを -Command で呼ぶと、Claude Code の拒否が素通りする
  • Claude Code のフックが1つも動かない（disableAllHooks が残っている）
  • Python で書いた Claude Code の拒否フックが、日本語のフォルダでだけ書き込みを通す
  • Claude Code のフックのパスを \ で書くと、フックが起動せず書き込みが通る（終了コード 127）
  • Windows の短い名前（8.3）で Claude Code に Write・Edit させると、元のファイル名が消える
  • claude -w -p が終わったあとも、git の worktree のロックが残って消せない
  • Claude Code の Bash ツールで、$$( を含むコマンドが「削除の安全確認」で止まる
  • Windows の Claude Code の Bash ツールで、\\（バックスラッシュ2つ）が \ 1つになる
  • Claude Code の PowerShell ツールで、cd したフォルダが次の呼び出しで元に戻る
  • Windows の Claude Code の Bash ツールで、%TEMP% の下への cd が次の呼び出しで取り消される
  • claude -p の --json-schema が、道具を絞った --agent を付けると黙って効かない（成功のまま）
  • サブフォルダの CLAUDE.md を一部だけ Read すると、残りが黙って読み込まれなくなる
  • リポジトリのサブフォルダで Claude Code を起動すると、ルートの .claude/settings.json のフックが効かない
