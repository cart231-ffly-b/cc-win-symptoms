H22

Claude Code の Edit・Write は、.md 以外のファイルで行末の空白を黙って消す（タブを空白に置き換えると、消えるだけ）

Claude Code タブ 空白 置き換え 消える · Claude Code Edit 行末 空白 消える

症状

Claude Code にタブを空白に揃えさせたら、タブが消えただけで空白が入っていない（a<TAB>b が ab になる）。ツールは置き換えが済んだと返す。Write で書いたファイルも、行末の空白が消えている。.md のファイルでは起きない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\case.txt", "a`tb`tc`n1`t2`t3`n")
Push-Location $d
"Use the Read tool on case.txt, then use the Edit tool once on case.txt with old_string set to exactly one TAB character, new_string set to exactly two space characters, and replace_all true. Use no other tools. Then stop." | claude -p --allowedTools "Read,Edit" | Out-Null
Pop-Location
$b = [IO.File]::ReadAllBytes("$d\case.txt")
"case.txt was 12 bytes with 4 tabs; asked to turn each tab into two spaces; now $($b.Length) bytes, tabs left: $(@($b | Where-Object { $_ -eq 9 }).Count)"
if ($b.Length -eq 12) { 'CANNOT CHECK (the Edit did not happen: check that claude -p can use Read and Edit)' } elseif ($b.Length -eq 8) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Edit と Write は、.md 以外のファイルでは、渡された文字列の各行の末尾の空白（空白とタブ）を取り除いてから書く（公式 issue #100296）。置き換え先が空白だけだと全部が行末の空白とみなされて空になり、置き換えが削除になる。

直し方

空白だけの置き換えや、行末の空白を残したい書き込みは、Edit・Write ではなくスクリプト（PowerShell の -replace や Python）でやらせ、終わったらバイト数や git diff で確かめる。CLAUDE.md にもそう書く。CLAUDE.md の型は本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

$t = [IO.File]::ReadAllText('C:/work/case.txt')
[IO.File]::WriteAllText('C:/work/case.txt', $t.Replace("`t", '  '))

作者の PC での結果

.txt でタブ1つを空白2つに Edit（replace_all）すると、タブが消えて空白は入らず 12→8 バイト。.md では空白2つが入った。Write も .txt では行末の空白が消え、.md では残った（2026-11-25、Claude Code 2.1.330、Windows 11）
