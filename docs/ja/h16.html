H16

Windows の Claude Code で Edit・Write すると、ファイル名の大文字小文字が黙って変わる

Claude Code ファイル名 小文字になる · Claude Code Edit ファイル名 変わる

症状

Claude Code に直させた Config.txt が、いつの間にか config.TXT のように大文字小文字の違う名前になっている。中身は正しく直っていて、ツールはいつもの「更新しました」としか言わない。Windows の git status には M としか出ない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\Sub" | Out-Null
[IO.File]::WriteAllText("$d\Sub\EditBack.txt", "fruit = APPLE`r`n")
Push-Location $d
"First use the Read tool on the file Sub/EditBack.txt in the current folder. Then use the Edit tool exactly once with file_path set to exactly this string, character for character: $d\sub\editback.TXT . Replace APPLE with ORANGE. Use no other tools. Then stop." | claude -p --allowedTools "Read,Edit" | Out-Null
Pop-Location
$name = (Get-ChildItem -LiteralPath "$d\Sub" | ForEach-Object Name) -join ', '
$body = (Get-Content -LiteralPath "$d\Sub\EditBack.txt" -Raw).Trim()
"file name after the Edit: $name; content: $body"
if ($body -notmatch 'ORANGE') { 'CANNOT CHECK (the Edit did not happen: check that claude -p can use Read and Edit)' } elseif ($name -ceq 'editback.TXT') { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Edit・Write に渡したパス（file_path）の大文字小文字が実際の名前と違うと、Claude Code は中身を直したうえで、ファイル名を file_path の綴りに変える（公式 issue #100987）。PowerShell の Set-Content など、ふつうの書き込みでは名前は変わらない。Windows の git は大文字小文字を区別しない設定がふつうなので、名前の変化が見えない。

直し方

Edit・Write の前に Glob や Read で実際の名前を確かめ、その綴りのまま file_path に書かせる。CLAUDE.md にもそう書く。commit の前に git -c core.ignorecase=false status --short で D と ?? の組が無いかを見る。CLAUDE.md の型は本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

git -c core.ignorecase=false status --short
# D Config.txt と ?? config.TXT が並んでいたら、名前が変わっている

作者の PC での結果

Read のあと Edit に ...\sub\editback.TXT を渡すと、EditBack.txt の中身が直り、名前が editback.TXT になった。/ 区切りでも Write でも同じ。Set-Content では Ctrl.txt のまま。git では M Config.txt としか出ず、core.ignorecase=false では D と ?? に分かれた（2026-11-25、Claude Code 2.1.330、Windows 11）
