H21

フックの .ps1 が見つからないと、onFailure: block でも書き込みが通る

onFailure block 効かない · Claude Code フック ps1 見つからない

症状

書き込みを止めるフックを powershell.exe -File <スクリプト> で呼び、onFailure: block も付けていたのに、スクリプトを移したあとから書き込みが止まらない。エラーも出ない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\.claude" | Out-Null
$settings = @'
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "powershell.exe",
            "args": ["-NoProfile", "-ExecutionPolicy", "Bypass", "-File", "${CLAUDE_PROJECT_DIR}/.claude/hooks/missing-script.ps1"],
            "onFailure": "block",
            "timeout": 30
          }
        ]
      }
    ]
  }
}
'@
[IO.File]::WriteAllText("$d\.claude\settings.json", $settings)
Push-Location $d
'Use the Write tool once to create out.txt with the text hi. Do not retry. Then reply done.' | claude -p --allowedTools Write | Out-Null
Pop-Location
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$d\.claude\hooks\missing-script.ps1" 2>$null | Out-Null
$code = $LASTEXITCODE
$w = Test-Path "$d\out.txt"
"exit code of powershell -File <missing .ps1>: $code; out.txt written despite onFailure block: $w"
if ($w) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

-File に渡した .ps1 が無いと、Windows PowerShell 5.1 は終了コード 0xFFFD0000（-196608）で終わる。Claude Code はこれを成功として扱い、onFailure: block が効かない（公式 issue #100891）。実行ファイルが無い・時間切れ・exit 1 なら止まる（issue による）。

直し方

フックのコマンドの中でスクリプトがあるかを確かめ、無ければ exit 1 で終わらせる。最後に exit $LASTEXITCODE を書けば、スクリプトの exit 2 もそのまま返る。

"command": "powershell.exe",
"args": ["-NoProfile", "-ExecutionPolicy", "Bypass", "-Command", "$s = 'C:/hooks/guard.ps1'; if (-not (Test-Path -LiteralPath $s -PathType Leaf)) { exit 1 }; $global:LASTEXITCODE = 0; & $s; if (-not $?) { if ($LASTEXITCODE) { exit $LASTEXITCODE } else { exit 1 } }; exit $LASTEXITCODE"],
"onFailure": "block"

作者の PC での結果

-File の .ps1 を置かずに Write させると、out.txt ができ、デバッグの記録は success だった。直接流した終了コードは -196608。上の形にすると、無い・exit 2・構文の誤り・throw の4通りで止まり、exit 0 は通った（2026-11-25、Claude Code 2.1.330、Windows PowerShell 5.1）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
