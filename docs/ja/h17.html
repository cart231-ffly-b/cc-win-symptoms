H17

リポジトリのサブフォルダで Claude Code を起動すると、ルートの .claude/settings.json のフックが効かない

Claude Code フック 効かない サブフォルダ · Claude Code settings.json 読まれない

症状

リポジトリの直下の .claude/settings.json に入れた書き込みを止めるフックが、ときどき動かない。動かなかった回は、エディタの端末やスクリプトが、リポジトリの下のフォルダで claude を起動していた。エラーも警告も出ない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$repo = Join-Path $d 'hookrepo'
New-Item -ItemType Directory -Force "$repo\.claude", "$repo\sub\deep" | Out-Null
Push-Location $repo; git init -q 2>$null; Pop-Location
$mark = ($repo + '\hook-ran.txt').Replace('\', '/')
$cmd = 'python -c "open(r''' + $mark + ''',''a'').write(''x'')"'
$settings = @{ hooks = @{ PreToolUse = @(@{ matcher = 'Read'; hooks = @(@{ type = 'command'; command = $cmd }) }) } } | ConvertTo-Json -Depth 8
[IO.File]::WriteAllText("$repo\.claude\settings.json", $settings)
[IO.File]::WriteAllText("$repo\sub\deep\a.txt", "hello`n")
[IO.File]::WriteAllText("$repo\a.txt", "hello`n")
$ran = @{}
foreach ($where in 'root', 'sub\deep') {
    Remove-Item -LiteralPath "$repo\hook-ran.txt" -ErrorAction SilentlyContinue
    Push-Location (Join-Path $repo ($where -replace 'root', ''))
    'Use the Read tool once on a.txt and reply done.' | claude -p --allowedTools Read | Out-Null
    Pop-Location
    $ran[$where] = Test-Path "$repo\hook-ran.txt"
}
"root hook ran when started at the repo root: $($ran['root']); when started in sub\deep: $($ran['sub\deep'])"
if (-not $ran['root']) { 'CANNOT CHECK (the hook did not run even at the root: check that python and git are installed)' } elseif (-not $ran['sub\deep']) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

公式の説明書のとおり、共有の .claude/settings.json は起動したフォルダから読む。.claude/settings.local.json はふつうリポジトリの直下のものを使うが、Windows では例外で起動したフォルダのものを使う。local の範囲で入れたプラグインも同じ理由でサブフォルダでは disabled になる（公式 issue #106149）。

直し方

必ず止めたいフックはユーザーの設定（~/.claude/settings.json）に入れる。無人のスクリプトは Push-Location でリポジトリの直下に移ってから claude -p を呼ぶ。

Push-Location C:/work/repo   # .claude/settings.json があるフォルダ
$prompt | claude -p
Pop-Location

この PC でほかの症状も起きるか調べる。doctor.ps1 の診断コマンドを表示

作者の PC での結果

直下の .claude/settings.json の PreToolUse フックは、直下で起動すると動き、sub/deep で起動すると動かなかった。.claude/settings.local.json に置いても同じ（2026-11-25、Claude Code 2.1.330、Windows 11）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。

  • Claude Code のフックのパスを \ で書くと、フックが起動せず書き込みが通る（終了コード 127）
