T02

PowerShell の -File で渡した2つ目の引数が、エラーなしで消える

powershell -File 配列 引数 渡せない · string[] 引数 1つしか入らない

症状

[string[]] の引数に -Path a b と2つ渡したのに、スクリプトには a しか入っていない。エラーも出ず、終了コードも 0。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\arr.ps1", 'param([string[]]$Path) "count=$($Path.Count) first=$($Path[0])"')
$o = powershell -NoProfile -ExecutionPolicy Bypass -File "$d\arr.ps1" -Path a b; $e = $LASTEXITCODE
"$o  exit=$e"
if ($o -eq 'count=1 first=a' -and $e -eq 0) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

-File で呼ぶと、引数は文字列のまま1つずつ渡る。-Path に入るのは a だけで、b はどの引数にも当たらない余りとして $args に回り、そのまま捨てられる。

直し方

param の前に [CmdletBinding()] を付ける。余った引数があるとエラーで止まるようになる。複数の値は1つの文字列で受けて、自分で分ける（次の T03）。

[CmdletBinding()]
param([string]$Path)
$paths = $Path -split ','
