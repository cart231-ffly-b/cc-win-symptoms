H19

ジャンクションの下で Claude Code を起動すると、作業フォルダが本当のパスに置き換わる（フックにも）

Claude Code ジャンクション パス · Claude Code cwd 変わる

症状

mklink /J で作ったジャンクションの下のフォルダで Claude Code を起動したのに、Claude が言う作業フォルダも、フックに届く cwd と file_path も、ジャンクションをたどった先の本当のパスになっている。起動したときの綴りで書いたフックの許可の範囲が、当たらなくなる。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$real = Join-Path $d 'real'
$link = Join-Path $d 'link'
New-Item -ItemType Directory -Force "$real\repo" | Out-Null
cmd /c mklink /J "$link" "$real" | Out-Null
git -C "$real\repo" init -q 2>$null
if (-not (Test-Path "$link\repo")) { 'CANNOT CHECK (could not create the junction with mklink /J)' } else {
Push-Location "$link\repo"
$init = 'reply ok' | claude -p --model haiku --output-format stream-json --verbose --max-turns 1 | Where-Object { $_ -match '"subtype":"init"' } | Select-Object -First 1
Pop-Location
$cwd = [regex]::Match([string]$init, '"cwd":"([^"]+)"').Groups[1].Value.Replace('\\', '\')
"launched in: $link\repo"
"init cwd   : $cwd"
if (-not $cwd) { 'CANNOT CHECK (no init line from claude -p: check that claude -p works and is logged in)' } elseif ($cwd -like '*\real\repo') { 'REPRODUCED' } else { 'NOT REPRODUCED' }
}

なぜ起きるか

Claude Code は、起動したフォルダのジャンクションをたどって、本当のパスを作業フォルダにする（公式 issue #106304。issue によると 2.1.312 までは起動したときの綴りのままだった）。会話の記録の置き場所も本当のパスで決まる。

直し方

フックでは、比べる両側を本当のパスにそろえてから比べる（Python なら os.path.realpath）。許可の範囲は本当のパスで書く。

import os
ok = os.path.normcase(os.path.realpath(target)).startswith(os.path.normcase(os.path.realpath(root)) + os.sep)

作者の PC での結果

link（real を指すジャンクション）の下の link/repo で起動すると、init の cwd は real/repo になり、会話の記録のフォルダも real の綴りだった。Write の前に動くフックにも cwd と file_path が real/repo の綴りで届いた（2026-11-25、Claude Code 2.1.330、Windows 11）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
