H14

Windows の Claude Code の Bash ツールは、7,400 文字ほどを超えるコマンドを動かさない（エラーは「引用符が閉じていない」）

unexpected EOF while looking for matching · Claude Code Bash 長いコマンド 動かない

症状

Claude Code が長いヒアドキュメントやスクリプトを Bash ツールで流すと、何も動かず unexpected EOF while looking for matching という引用符のエラーが返る。コマンドに引用符の間違いは無い。単引用符ばかりの中身なら、1,500 文字ほどのコマンドでも起きる。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$hook = @'
import json, sys
from pathlib import Path
d = json.load(sys.stdin)
if d.get("tool_name") != "Bash":
    sys.exit(0)
n = int(Path("n.txt").read_text().strip())
cmd = "printf %s '" + "A" * n + "' > o.txt; echo ok > d.txt"
print(json.dumps({"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "allow", "updatedInput": {"command": cmd}}}))
'@
[IO.File]::WriteAllText("$d\hook.py", $hook)
$hp = ($d + '\hook.py').Replace('\', '/')
[IO.File]::WriteAllText("$d\s.json", '{"hooks":{"PreToolUse":[{"matcher":"Bash","hooks":[{"type":"command","command":"python \"HP\""}]}]}}'.Replace('HP', $hp))
$ok = @{}
Push-Location $d
foreach ($n in 7000, 7600) {
    Remove-Item -LiteralPath "$d\o.txt", "$d\d.txt" -ErrorAction SilentlyContinue
    [IO.File]::WriteAllText("$d\n.txt", "$n")
    'Use the Bash tool once to run: echo hi . Then stop.' | claude -p --settings s.json --allowedTools Bash | Out-Null
    $ok[$n] = (Test-Path "$d\d.txt")
}
Pop-Location
"a 7000-A command ran to the end: $($ok[7000]); a 7600-A command ran to the end: $($ok[7600])"
if (-not $ok[7000]) { 'CANNOT CHECK (even the 7000-character command did not run: check that python is installed and the Bash tool works)' } elseif (-not $ok[7600]) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Windows の Claude Code は、Bash ツールのコマンドを準備と後始末の部分で包み、bash.exe -c の1つの文字列にして渡す。Git for Windows の bash はこの文字列を 8,186 文字までしか受け取らず、残りを捨てる（公式 issue #102533）。包む部分を引くと、書けるコマンドは作者の PC で 7,400 文字前後。issue によると単引用符は5文字に書き換えられ、1つで5文字ぶん使う。

直し方

長いスクリプトやヒアドキュメントは、Write ツールでファイルに書いてから bash script.sh のように短いコマンドで動かす。CLAUDE.md にもそう書いておく。Claude Code 自身にこう書かせる CLAUDE.md の型は、本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

# CLAUDE.md
- Windows では Bash ツールのコマンドに長いスクリプトやヒアドキュメントを書かない（上限は 7,000 文字台、単引用符は1つで5文字ぶん）
- 数千文字を超えそうなものは Write ツールでファイルに書いてから bash <ファイル> で動かす

この PC でほかの症状も起きるか調べる。doctor.ps1 の診断コマンドを表示

再発を防ぐ設計と実装を読む。0〜4章を無料で読む（Zenn、全章 1,200円）

作者の PC での結果

Bash ツールに渡るコマンドを PreToolUse フックで差し替えると、7,417 文字は動き、7,421 文字は何も動かなかった。単引用符 1,450 個（1,495 文字）は動き、1,500 個（1,545 文字）は動かなかった。9,000 文字の中身をファイルに書いて bash big.sh は動いた（2026-11-25、Claude Code 2.1.330、Git for Windows 2.56.0）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
