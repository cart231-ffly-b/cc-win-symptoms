H10

Windows の Claude Code の Bash ツールで、\\（バックスラッシュ2つ）が \ 1つになる

Claude Code Bash バックスラッシュ 消える · Claude Code Windows backslash

症状

Claude Code に Bash ツールで書かせたスクリプトや正規表現で、\\ のはずの所が \ 1つになっている。単引用符の中でも、引用符付きのヒアドキュメントの中でも起きる。エラーは出ず、壊れた中身のまま動く。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\p.txt", 'Use the Bash tool once to run exactly this command and nothing else, then stop: printf ''%s'' ''a\\b'' > out.bin')
Push-Location $d
Get-Content "$d\p.txt" -Raw | claude -p --allowedTools Bash | Out-Null
Pop-Location
if (-not (Test-Path "$d\out.bin")) { 'CANNOT CHECK (out.bin was not written: check that the Bash tool is available and allowed)' } else {
$b = [IO.File]::ReadAllBytes("$d\out.bin")
"asked for a, two backslashes, b -> bytes written: " + (($b | ForEach-Object { '{0:x2}' -f $_ }) -join ' ')
if ($b.Length -eq 3) { 'REPRODUCED' } else { 'NOT REPRODUCED' }
}

なぜ起きるか

Windows（Git for Windows）の Claude Code の Bash ツールは、渡されたコマンドの中の \\ を \ 1つに変えてから実行する。モデルが送ったコマンドには2つ入っている（会話の記録で確かめられる）。4つは2つになり、1つは1つのまま（公式 issue #110308）。

直し方

バックスラッシュを含む本文（スクリプト・正規表現・Windows のパス）は、Bash のコマンドやヒアドキュメントに書かず、Write ツールでファイルに保存してから使う。Windows のパスは / 区切りで書く。Claude Code 自身にこう書かせる CLAUDE.md の型は、本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

# 本文は Write ツールでファイルに保存し、コマンドではファイルを読むだけにする
python fix.py
