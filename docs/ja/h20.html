Claude Code の PowerShell ツールは、途中のコマンドの終了コードで、成功を「失敗」と返す

Claude Code PowerShell Exit code 1 robocopy · Claude Code PowerShell ツール 失敗 成功してるのに

症状

Claude Code が PowerShell ツールで robocopy などを動かすと、コピーはできているのに Exit code 1 の失敗として返り、Claude がやり直したり、コマンドを書き換えたりする。最後の文は成功している。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\s.json", '{"env":{"CLAUDE_CODE_USE_POWERSHELL_TOOL":"1"}}')
Push-Location $d
$out = "You must use the PowerShell tool (not Bash). Run exactly the PowerShell command in the next line once, then stop.`ncmd /c exit 3; 'done'" | claude -p --settings s.json --allowedTools PowerShell --output-format stream-json --verbose | Out-String
Pop-Location
$ran = $out -match 'done'
$err = $out -match '"is_error":true'
"the PowerShell tool ran the command: $ran; the call was reported as an error: $err"
if (-not $ran) { 'CANNOT CHECK (the PowerShell tool did not run: check that claude -p can use it)' } elseif ($err -and ($out -match 'Exit code 3')) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

PowerShell では、外のプログラムの終了コードが $LASTEXITCODE に残る。PowerShell ツールは、最後に残った $LASTEXITCODE を呼び出し全体の結果として返す（公式 issue #97589）。ふつうの powershell -Command や -File では、同じコマンドの終了コードは 0 になる。robocopy は成功でも 1〜7 を返す。

直し方

成功でも 0 以外を返すコマンド（robocopy・findstr・git diff --quiet など）のあとは、終わりに exit 0 を付け、終了コードは文字で出す。本当の失敗も失敗扱いにならなくなるので、出した exit= の行を読ませる。

robocopy src dst a.txt | Out-Null; $rc = $LASTEXITCODE; if ($rc) { "exit=$rc" }; exit 0

作者の PC での結果

PowerShell ツールで cmd /c exit 3; 'done' は done まで動いたのに is_error=true・Exit code 3。robocopy で1つコピーしても Exit code 1 の失敗（コピーはできていた）。; exit 0 を足すと失敗にならない。ふつうの powershell -Command と -File では 0（2026-11-25、Claude Code 2.1.330、Windows PowerShell 5.1）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
