Claude Code のフックが効かない・素通りする原因と対策まとめ

PreToolUse の拒否が素通りする、settings.json のフックが読まれない、パス判定がずれるときの確認手順。

起動しない

症状ページ起きること
Claude Code のフックが1つも動かない（disableAllHooks が残っている）書き込みを止めるフックも、通知のフックも、何も動かない。エラーも警告も出ない。試しに一時的に止めたつもりの設定が、そのまま残っていることがある。
Claude Code のフックのパスを \ で書くと、フックが起動せず書き込みが通る（終了コード 127）書き込みを拒否するフックを入れたのに、ファイルが書かれた。フックのスクリプトは、手で動かすと確かに拒否する。設定の command に C:\...\deny.cmd のような \ 区切りのパスか、空白入りのパスを囲まずに書いている。エラーも警告も出ない。
リポジトリのサブフォルダで Claude Code を起動すると、ルートの .claude/settings.json のフックが効かないリポジトリの直下の .claude/settings.json に入れた書き込みを止めるフックが、ときどき動かない。動かなかった回は、エディタの端末やスクリプトが、リポジトリの下のフォルダで claude を起動していた。エラーも警告も出ない。
フックの .ps1 が見つからないと、onFailure: block でも書き込みが通る書き込みを止めるフックを powershell.exe -File <スクリプト> で呼び、onFailure: block も付けていたのに、スクリプトを移したあとから書き込みが止まらない。エラーも出ない。

拒否が通らない

症状ページ起きること
Claude Code の PreToolUse フックが、タイムアウト（時間切れ）になると書き込みを止めずに通す書き込みを拒否するフックを入れてあるのに、ファイルが書かれた。画面にも結果の JSON にもエラーや警告は出ない。フックの答えが時間制限より遅れたときだけ起きる。
PowerShell のフックを -Command で呼ぶと、Claude Code の拒否が素通りするexit 2 で拒否する PowerShell スクリプトをフックにしたのに、書き込みが通る。スクリプトを手で動かすと確かに 2 を返す。
Python で書いた Claude Code の拒否フックが、日本語のフォルダでだけ書き込みを通す書き込みを全部拒否するフックを Python で書いた。英数字のフォルダでは止まるのに、名前が日本語のフォルダへの書き込みは通る。エラーも警告も出ない。

パス判定がずれる

症状ページ起きること
ジャンクションの下で Claude Code を起動すると、作業フォルダが本当のパスに置き換わる（フックにも）mklink /J で作ったジャンクションの下のフォルダで Claude Code を起動したのに、Claude が言う作業フォルダも、フックに届く cwd と file_path も、ジャンクションをたどった先の本当のパスになっている。起動したときの綴りで書いたフックの許可の範囲が、当たらなくなる。
Git Bash のフックで $PWD と file_path を比べると、Windows ではプロジェクトの中まで「外」になるLinux で動いていた「プロジェクトの外には書かせない」bash のフックが、Windows では中への書き込みまで全部止める。.claude/settings.json を直そうとしても止められる。

設定を確かめる手順

  1. その行を消す（または false にする）。確かめるコードの最初の行に、あなたの設定ファイルごとの値が出る。（H03）
  2. 必ず止めたいフックはユーザーの設定（~/.claude/settings.json）に入れる。無人のスクリプトは Push-Location でリポジトリの直下に移ってから claude -p を呼ぶ。（H17）
  3. パスは / 区切りで書き、全体を " で囲む（JSON の中では \"）。（H05）
  4. PowerShell のフックは -File で呼ぶ。（H02）
  5. フックのコマンドの中でスクリプトがあるかを確かめ、無ければ exit 1 で終わらせる。最後に exit $LASTEXITCODE を書けば、スクリプトの exit 2 もそのまま返る。（H21）
  6. 関所のフックに "onFailure": "block" を付ける（Claude Code 2.1.295 以降）。付けたら、フックが動かない PC では書き込みが全部止まるので、1回試す。（H01）
