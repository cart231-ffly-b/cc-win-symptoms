T03

PowerShell の -File で a,b と渡すと、配列にならず1つの文字列になる

powershell -File カンマ 配列にならない · a,b 1つのパス

症状

-Path a,b と書けば2つのパスになるつもりが、a,b という名前のパス1つとして扱われ、「見つからない」になるか、黙って何もしない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\arr.ps1", 'param([string[]]$Path) "count=$($Path.Count) first=$($Path[0])"')
$o = powershell -NoProfile -ExecutionPolicy Bypass -File "$d\arr.ps1" -Path a,b
$o
if ($o -eq 'count=1 first=a,b') { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

-File で渡した引数は PowerShell の式として解釈されない。カンマで配列を作るのは、PowerShell の中で呼んだときだけ。

直し方

1つの文字列で受けて、スクリプトの中で -split ',' で分ける。

param([string]$Path)
foreach ($p in ($Path -split ',')) { $p.Trim() }
