H05

Claude Code のフックのパスを \ で書くと、フックが起動せず書き込みが通る（終了コード 127）

Claude Code フック 動かない パス · Claude Code hook 127

症状

書き込みを拒否するフックを入れたのに、ファイルが書かれた。フックのスクリプトは、手で動かすと確かに拒否する。設定の command に C:\...\deny.cmd のような \ 区切りのパスか、空白入りのパスを囲まずに書いている。エラーも警告も出ない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$cmd = (@('@echo off', 'more > nul', 'echo x> "MARK"', 'exit /b 2') -join "`r`n").Replace('MARK', "$d\called.txt")
[IO.File]::WriteAllText("$d\deny.cmd", $cmd + "`r`n")
$fwd = '\"' + ($d -replace '\\', '/') + '/deny.cmd\"'
$back = ($d + '\deny.cmd') -replace '\\', '\\'
foreach ($k in @('fwd', 'back')) {
  $w = Join-Path $d $k; New-Item -ItemType Directory $w -Force | Out-Null
  $hook = if ($k -eq 'fwd') { $fwd } else { $back }
  [IO.File]::WriteAllText("$w\s.json", '{"hooks":{"PreToolUse":[{"matcher":"Write|Edit","hooks":[{"type":"command","command":"HOOK"}]}]}}'.Replace('HOOK', $hook))
  Push-Location $w
  'Use the Write tool once to create the file written.txt with the content hi. Do not retry if it is blocked.' | claude -p --settings s.json --permission-mode acceptEdits | Out-Null
  Pop-Location
  if ($k -eq 'fwd') { $c = Test-Path "$d\called.txt" }
}
$wf = Test-Path "$d\fwd\written.txt"; $wb = Test-Path "$d\back\written.txt"
"same deny.cmd: quoted C:/.../deny.cmd -> hook called=$c, written=$wf; unquoted C:\...\deny.cmd -> written=$wb"
if ((-not $c) -or $wf) { 'CANNOT CHECK (the quoted forward-slash hook did not block: check Git for Windows, disableAllHooks or your settings)' } elseif ($wb) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Git for Windows が入った Windows では、Claude Code はフックの command を Git Bash のコマンド行として動かす。bash にとって \ は「次の1文字をそのまま使う」記号なので、C:\Users\me\deny.cmd は C:Usersmedeny.cmd という無いコマンドになる。空白入りのパスは空白で切られる。どちらも終了コード 127（コマンドが見つからない）で、PreToolUse では 0 と 2 以外は「止めないエラー」なので、書き込みは進む。claude -p の結果には何も出ず、--debug のログに status 127 が残る（公式 issue #109103 と同じ）。

直し方

パスは / 区切りで書き、全体を " で囲む（JSON の中では \"）。関所のフックには "onFailure": "block" も付ける（起動できなかったときも止まる。Claude Code 2.1.295 以降）。

"command": "\"C:/Users/me/hooks/deny.cmd\"",
"onFailure": "block"

作者の PC での結果

同じ deny.cmd で、/ 区切りは止まり、\ 区切りと、空白入りを囲まない書き方は書き込まれた（debug に status 127）。onFailure: block を足すと止まった（2026-11-24、Claude Code 2.1.330）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
