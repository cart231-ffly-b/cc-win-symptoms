C02

Codex CLI が PowerShell 5.1 で読んだ UTF-8（BOM なし）の日本語が化ける（終了コード 0）

Codex CLI 文字化け Get-Content · Codex CLI Windows 日本語 化ける

症状

Codex CLI に、BOM なしの UTF-8 で保存した日本語のファイル（Markdown など）を読ませると、「繝｡繝｢」のような化けた文字で読む。終了コードは 0 で、Codex は化けたまま「そのまま写した」と答える。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$s = [string][char]0x65E5 + [char]0x672C + [char]0x8A9E
[IO.File]::WriteAllText("$d\note.md", $s, [Text.UTF8Encoding]::new($false))
$a = Get-Content -LiteralPath "$d\note.md"
$b = Get-Content -LiteralPath "$d\note.md" -Encoding UTF8
"default read equals the file: $($a -eq $s); with -Encoding UTF8: $($b -eq $s)"
if ($a -ne $s -and $b -eq $s) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

PowerShell 7 が無いと、Codex は Windows PowerShell 5.1 の Get-Content でファイルを読む。5.1 は BOM の無いファイルを、日本語の Windows では cp932（Shift_JIS）として読むので、UTF-8 の日本語が化ける（公式 issue openai/codex #29085。報告はトルコ語だが日本語でも起きる）。

直し方

読むときに -Encoding UTF8 を付ける。Codex に任せるなら、プロジェクトの AGENTS.md に「Get-Content は -Encoding UTF8 で」と書く（効きやすくなるが、確実ではない）。

Get-Content -Encoding UTF8 note.md

この PC でほかの症状も起きるか調べる。doctor.ps1 の診断コマンドを表示

安全装置、無人実行、CLAUDE.md の型の実装と設計を本にまとめています。0〜4章を無料で読む（Zenn、全章 1,200円）

作者の PC での結果

既定の Get-Content は化けた（「メモ」が「繝｡繝｢」に）、-Encoding UTF8 は元のとおり（2026-11-27、codex-cli 0.167.0-alpha.3.2、Windows PowerShell 5.1.26100、コードページ 932）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
