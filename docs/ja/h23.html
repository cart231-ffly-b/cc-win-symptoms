H23

Git Bash のフックで $PWD と file_path を比べると、Windows ではプロジェクトの中まで「外」になる

症状

Linux で動いていた「プロジェクトの外には書かせない」bash のフックが、Windows では中への書き込みまで全部止める。.claude/settings.json を直そうとしても止められる。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\.claude\hooks" | Out-Null
Push-Location $d; git init -q 2>$null; Pop-Location
$sh = @'
f=$(python -c "import sys,json; print(json.load(sys.stdin)['tool_input'].get('file_path',''))")
printf 'PWD=%s\nfile_path=%s\n' "$PWD" "$f" > seen.txt
case "$f" in "$PWD"/*) exit 0;; *) echo "BLOCKED: file outside the project" >&2; exit 2;; esac
'@
[IO.File]::WriteAllText("$d\.claude\hooks\guard.sh", $sh.Replace("`r`n", "`n"))
[IO.File]::WriteAllText("$d\.claude\settings.json", '{"hooks":{"PreToolUse":[{"matcher":"Write","hooks":[{"type":"command","command":"bash .claude/hooks/guard.sh"}]}]}}')
Push-Location $d
'Use the Write tool once to create out.txt in the current folder with the text hi. Do not retry. Then reply done.' | claude -p --allowedTools Write | Out-Null
Pop-Location
if (Test-Path "$d\seen.txt") { Get-Content "$d\seen.txt" }
$w = Test-Path "$d\out.txt"
"write inside the project went through: $w"
if (-not (Test-Path "$d\seen.txt")) { 'CANNOT CHECK (the hook did not run: check that python, git and Git for Windows bash are installed)' } elseif (-not $w) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

フックに届く tool_input.file_path は C:\... の Windows の形。Git Bash の $PWD は /c/...・/tmp/...・C:/... の形で、文字のまま比べると先頭が一致しない（公式 issue #94256）。止める場所を書いた守りなら、逆に何も止めない。

直し方

比べる両方を cygpath -u でそろえてから比べる。file_path だけでは足りない（$PWD が C:/... の形で来ることがある）。安全装置を Python で書き realpath でそろえる形は本の5章（https://zenn.dev/kamijo_aoto/books/windows-claude-code-traps ）にある。

u() { cygpath -u "$1" 2>/dev/null || printf '%s' "$1"; }
f=$(u "$f"); p=$(u "$PWD")
case "$f" in "$p"/*) exit 0;; *) echo "BLOCKED" >&2; exit 2;; esac

作者の PC での結果

file_path は C:\...\out.txt、$PWD は回によって /tmp/... か C:/... の形で、プロジェクトの中への Write が止まった。両方を cygpath -u でそろえると、中は通り隣のフォルダは止まった（2026-11-25、Claude Code 2.1.330、Git for Windows）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。
