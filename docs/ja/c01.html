C01

Codex CLI が PowerShell 5.1 でパイプに渡した日本語が ? になる（終了コード 0）

Codex CLI 文字化け ? · Codex CLI Windows 日本語 パイプ

症状

Codex CLI に、日本語を含む文字列を python などのコマンドへパイプで渡させると、受け取った側には ? が届く。コマンドは終了コード 0 で終わり、Codex も化けに気づかずにそのまま答える。PowerShell 7 が無い Windows で、Codex が Windows PowerShell 5.1 でコマンドを動かすときに起きる。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$pyv = & python -c "import sys; print('%d.%d.%d' % sys.version_info[:3])" 2>$null
if (-not $pyv) { 'CANNOT CHECK (python not found, or only the Microsoft Store stub: install Python from python.org)' } else {
"python $pyv"
[IO.File]::WriteAllText("$d\hex.py", 'import sys; print(sys.stdin.buffer.read().strip().hex())')
$s = 'Zo' + [char]0xE9 + ' ' + [char]0x65E5 + [char]0x672C
$h = $s | python "$d\hex.py"
"bytes=$h  (UTF-8 would be 5a6fc3a920e697a5e69cac)"
if ($h -match '3f') { 'REPRODUCED' } else { 'NOT REPRODUCED' }
}

なぜ起きるか

PowerShell 7 が無いと、Codex は powershell.exe（5.1）の -Command でコマンドを動かす。5.1 は外部のコマンドに渡す文字を $OutputEncoding で符号化し、その既定が ASCII なので、ASCII にない文字はすべて ? になる（公式 issue openai/codex #64139）。T04 と同じ仕組み。

直し方

パイプの前に $OutputEncoding を UTF-8 にする。Codex に任せるなら、プロジェクトの AGENTS.md に「パイプの前に $OutputEncoding を UTF-8 にする」と書く（効きやすくなるが、確実ではない）。

$OutputEncoding = [Text.UTF8Encoding]::new($false)
'Zoé 日本' | python -c "import sys; print(sys.stdin.buffer.read().hex())"
