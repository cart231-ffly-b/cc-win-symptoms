PowerShell の "..." に書いた Markdown のバッククォートで、文字が消えて改行が入る

PowerShell バッククォート 消える · ヒアストリング Markdown 文字化け

症状

"..." や @"..."@ に `night-shift` のようなコード表記を書くと、n が消えて改行になる。`true` なら t が消えてタブ。エラーは出ず、ファイルの一部が欠けるだけ。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$t = "use `night-shift and `true."
$t
if ($t -match "`n" -or $t -match "`t") { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

バッククォートは PowerShell のエスケープ文字。`n は改行、`t はタブ、`0 は NUL として解釈される。

直し方

バッククォートを含む文章は単一引用符のヒアストリング @'...'@ に書き、差し込みは .Replace() で行う。書いたら出力を読み返す。

$tpl = @'
use `night-shift` and `NAME`.
'@
$text = $tpl.Replace('NAME', $name)
