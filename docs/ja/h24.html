H24

Claude Code の Grep は、作業フォルダの下を探すとき、glob の */ が「見つからない」になる

Claude Code Grep No files found あるのに · Claude Code Grep glob 見つからない

症状

Claude Code が Grep で探して No files found と返し、「そのファイルはありません」と判断する。実際にはファイルがある。探す範囲（path）を作業フォルダの下にして、glob に */ を使っていた。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\a\b\sub" | Out-Null
[IO.File]::WriteAllText("$d\a\b\sub\SKILL.md", "markerterm`n")
Push-Location $d
$found = @()
foreach ($g in '**/SKILL.md', '*/SKILL.md') {
    $out = "Use the Grep tool exactly once with pattern set to markerterm, path set to exactly $d\a\b , glob set to exactly $g , and output_mode files_with_matches. Use no other tools. Then stop." | claude -p --allowedTools Grep --output-format stream-json --verbose | Out-String
    $found += ($out -match 'Found 1 file')
}
Pop-Location
"glob **/SKILL.md found the file: $($found[0]); glob */SKILL.md found the file: $($found[1])"
if (-not $found[0]) { 'CANNOT CHECK (even **/SKILL.md found nothing: check that claude -p can use Grep)' } elseif (-not $found[1]) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Grep の glob は、path からではなく作業フォルダからの相対パスで照らし合わされる（公式 issue #104991）。path が a\b でも sub\SKILL.md は a/b/sub/SKILL.md として照らされるので、1段だけの */SKILL.md には当たらない。**/ はどの深さにも当たる。

直し方

glob は **/ で書く。CLAUDE.md にもそう書き、No files found のときは glob を外して探し直させる。CLAUDE.md の型は本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

# CLAUDE.md
- Grep の glob は作業フォルダからの相対で照らされる。*/ ではなく **/ で書く
- No files found のときは、glob を外してもう一度探す
