H01

Claude Code の PreToolUse フックが、時間切れになると書き込みを止めずに通す

症状

書き込みを拒否するフックを入れてあるのに、ファイルが書かれた。画面にも結果の JSON にもエラーや警告は出ない。フックの答えが時間制限より遅れたときだけ起きる。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\slow-deny.ps1", '[IO.File]::WriteAllText(''MARK'', ''x''); Start-Sleep -Seconds 15; [Console]::Error.WriteLine("denied"); exit 2'.Replace('MARK', "$d\called.txt"))
$hook = 'powershell -NoProfile -ExecutionPolicy Bypass -File \"' + ($d -replace '\\', '/') + '/slow-deny.ps1\"'
[IO.File]::WriteAllText("$d\s.json", '{"hooks":{"PreToolUse":[{"matcher":"Write|Edit","hooks":[{"type":"command","command":"HOOK","timeout":3}]}]}}'.Replace('HOOK', $hook))
Push-Location $d
'Use the Write tool once to create the file written.txt with the content hi. Do not retry if it is blocked.' | claude -p --settings s.json --permission-mode acceptEdits | Out-Null
Pop-Location
$w = Test-Path "$d\written.txt"; $c = Test-Path "$d\called.txt"
"hook denies after 15 s, timeout 3 s: hook called=$c, written=$w"
if (-not $c) { 'CANNOT CHECK (the hook was never called: check disableAllHooks or your settings)' } elseif ($w) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

既定では、フックが時間切れ・異常終了・起動失敗になると、Claude Code はツールの呼び出しを止めずに先へ進める。公式の hooks リファレンスにも「止まったフックを関所として当てにしない」とある。

直し方

関所のフックに "onFailure": "block" を付ける（Claude Code 2.1.295 以降）。付けたら、フックが動かない PC では書き込みが全部止まるので、1回試す。時間制限は短くしすぎない。

{"type": "command", "command": "...", "timeout": 60, "onFailure": "block"}

作者の PC での結果

15秒待って拒否するフックを時間制限3秒で試し、2回とも書き込まれた。onFailure: block を足すと止まった

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。

こんな言葉で探した人へ

  • Claude Code フック 効かない
  • PreToolUse フック タイムアウト
  • Claude Code hook 素通り
  • onFailure block

関連

この穴を最初から踏まないようにした部品（書き込み先を絞る安全装置〈onFailure: block 付き〉、夜の無人実行、ファイルとフックの設定を調べる健康診断、CLAUDE.md の型、試験一式）は cc-win-kit にまとめています。

cc-win-kit（note、2,980円）

ほかの症状

  • PowerShell の終了コードが、2 を返したのに 1 になる
  • -File で渡した2つ目の引数が、エラーなしで消える
  • -File で a,b と渡すと、配列にならず1つの文字列になる
  • パイプで渡した日本語が ? になる（claude -p・python・git）
  • python や claude の出力を変数に入れると文字化けする
  • 手で動かすと通る Python が、タスクスケジューラやリダイレクトのときだけ落ちる
  • PYTHONIOENCODING を設定したのに、python -I だと効かない
  • 日本語入りの .ps1 が、構文エラーになるか文字化けして動く
  • .cmd / .bat のコメントが、コマンドとして実行される
  • powershell -Command の1行に書いた $変数 が、呼ぶ前に消える
  • Get-ChildItem の -Include が効かず、全部のファイルが返る
  • "..." に書いた Markdown のバッククォートで、文字が消えて改行が入る
  • 書き込み中のログが 0 バイトに見える
  • claude -p --allowedTools の後ろに書いたプロンプトが飲み込まれる
  • PowerShell のフックを -Command で呼ぶと、Claude Code の拒否が素通りする
  • Claude Code のフックが1つも動かない（disableAllHooks が残っている）
