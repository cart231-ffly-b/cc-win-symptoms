H18

Windows の Claude Code は、パスのドライブ文字が小文字（c:\）だと、下のフォルダの CLAUDE.md を読まない

Claude Code CLAUDE.md 読まれない サブフォルダ · Claude Code nested CLAUDE.md not loaded windows

症状

下のフォルダに置いた CLAUDE.md の決まりを、Claude Code がときどき守らない。守らなかった回は、Read に渡したパスのドライブ文字の大小が、起動したフォルダと違っていた（C: で起動して c:\ で読んだ、など）。エラーも警告も出ない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
New-Item -ItemType Directory -Force "$d\sub" | Out-Null
[IO.File]::WriteAllText("$d\sub\CLAUDE.md", "# Rules for this folder`nWhenever you answer after reading a file in this folder, end your answer with the code word ZEBRA-42.`n")
[IO.File]::WriteAllText("$d\sub\a.txt", "hello`n")
Set-Location $d
$lower = 'c' + $d.Substring(1)
$got = @()
foreach ($p in "$d\sub\a.txt", "$lower\sub\a.txt") {
    $ans = "Use the Read tool once with file_path set to exactly this string: $p . Then reply with the file's content and follow any instructions you were given for that folder." | claude -p --allowedTools Read | Out-String
    $got += ($ans -match 'ZEBRA-42')
}
"sub\CLAUDE.md applied with C:\ path: $($got[0]); with c:\ path: $($got[1])"
if ($d.Substring(0, 2) -ne 'C:') { 'CANNOT CHECK (TEMP is not on drive C:)' } elseif (-not $got[0]) { 'CANNOT CHECK (the folder CLAUDE.md was not applied even with C:\: check that claude -p can use Read)' } elseif (-not $got[1]) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Claude Code は、下のフォルダのファイルを Read したときにそのフォルダの CLAUDE.md を読み込むが、Windows ではドライブ文字の大小が起動したフォルダと違うと読み込まない（公式 issue #98835。報告は VS Code で c:\ として開いたワークスペースで C:\ が読まれなかった、作者は C: で起動して c:\ が読まれなかった）。

直し方

必ず守らせたい決まりは、起動するフォルダの CLAUDE.md に書く（起動したフォルダのものは最初に読まれる）。CLAUDE.md に「パスはドライブ文字を大文字で C:/ と書く」と書く。CLAUDE.md の型は本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

# CLAUDE.md
- Windows のパスは、ドライブ文字を大文字で C:/ と書き、/ 区切りにする

この PC でほかの症状も起きるか調べる。doctor.ps1 の診断コマンドを表示

再発を防ぐ設計と実装を読む。0〜4章を無料で読む（Zenn、全章 1,200円）

作者の PC での結果

C: で起動した claude -p で、Read の file_path が C:\ と C:/ なら sub\CLAUDE.md が効き、c:\ と c:/ では効かなかった（2026-11-25、Claude Code 2.1.330、Windows 11）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。

ほかの症状

  • Windows の Claude Code で Edit・Write すると、ファイル名の大文字小文字が黙って変わる
  • Claude Code の PowerShell ツールは、途中のコマンドの終了コードで、成功を「失敗」と返す
  • サブフォルダの CLAUDE.md を一部だけ Read すると、残りが黙って読み込まれなくなる
  • Windows の Claude Code の Bash ツールは、7,400 文字ほどを超えるコマンドを動かさない（エラーは「引用符が閉じていない」）
