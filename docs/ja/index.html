Windows で Claude Code が黙って壊れるとき

エラーは出ないのに、結果だけが違う。Windows で起きる Claude Code のフックの素通りや、PowerShell・Codex CLI の文字化けなどの症状に、確かめ方・原因・直し方を添えました。どれも作者の PC で実際に起きたものです。

この PC でまとめて確かめる

Windows PowerShell 5.1 に貼ると、この PC で再現する症状と、各症状のページを一覧で表示します。

irm https://cart231-ffly-b.github.io/cc-win-symptoms/doctor.ps1 | iex

データはアップロードしません。管理者権限は不要です。書き込み先は専用の一時フォルダだけで、実行後に削除します。

通信が必要な Claude のチェックは省きます。時間のかかるローカルチェックを含めるには、先に $env:CCDOCTOR_ALL='1' を実行します。

安全装置、無人実行、CLAUDE.md の型の実装と設計を本にまとめています。0〜4章を無料で読む（Zenn、全章 1,200円）

Claude Code のフック

  1. H01
    Claude Code の PreToolUse フックが、タイムアウト（時間切れ）になると書き込みを止めずに通す
  2. H02
    PowerShell のフックを -Command で呼ぶと、Claude Code の拒否が素通りする
  3. H03
    Claude Code のフックが1つも動かない（disableAllHooks が残っている）
  4. H04
    Python で書いた Claude Code の拒否フックが、日本語のフォルダでだけ書き込みを通す
  5. H05
    Claude Code のフックのパスを \ で書くと、フックが起動せず書き込みが通る（終了コード 127）
  6. H17
    リポジトリのサブフォルダで Claude Code を起動すると、ルートの .claude/settings.json のフックが効かない
  7. H19
    ジャンクションの下で Claude Code を起動すると、作業フォルダが本当のパスに置き換わる（フックにも）
  8. H21
    フックの .ps1 が見つからないと、onFailure: block でも書き込みが通る
  9. H23
    Git Bash のフックで $PWD と file_path を比べると、Windows ではプロジェクトの中まで「外」になる

Claude Code のツール・CLAUDE.md

  1. H06
    Windows の短い名前（8.3）で Claude Code に Write・Edit させると、元のファイル名が消える
  2. H07
    Claude Code で裏の Bash を TaskStop で止めても、& やパイプで動かしたプロセスが残る
  3. H08
    claude -w -p が終わったあとも、git の worktree のロックが残って消せない
  4. H09
    Claude Code の Bash ツールで、$$( を含むコマンドが「削除の安全確認」で止まる
  5. H10
    Windows の Claude Code の Bash ツールで、\\（バックスラッシュ2つ）が \ 1つになる
  6. H11
    Windows の Claude Code の Bash ツールで、%TEMP% の下への cd が次の呼び出しで取り消される
  7. H12
    Claude Code の PowerShell ツールで、cd したフォルダが次の呼び出しで元に戻る
  8. H13
    claude -p の --json-schema が、道具を絞った --agent を付けると黙って効かない（成功のまま）
  9. H14
    Windows の Claude Code の Bash ツールは、7,400 文字ほどを超えるコマンドを動かさない（エラーは「引用符が閉じていない」）
  10. H15
    サブフォルダの CLAUDE.md を一部だけ Read すると、残りが黙って読み込まれなくなる
  11. H16
    Windows の Claude Code で Edit・Write すると、ファイル名の大文字小文字が黙って変わる
  12. H18
    Windows の Claude Code は、パスのドライブ文字が小文字（c:\）だと、下のフォルダの CLAUDE.md を読まない
  13. H20
    Claude Code の PowerShell ツールは、途中のコマンドの終了コードで、成功を「失敗」と返す
  14. H22
    Claude Code の Edit・Write は、.md 以外のファイルで行末の空白を黙って消す（タブを空白に置き換えると、消えるだけ）
  15. H24
    Claude Code の Grep は、作業フォルダの下を探すとき、glob の */ が「見つからない」になる

PowerShell・Python・cmd

  1. T01
    PowerShell の終了コードが、2 を返したのに 1 になる
  2. T02
    PowerShell の -File で渡した2つ目の引数が、エラーなしで消える
  3. T03
    PowerShell の -File で a,b と渡すと、配列にならず1つの文字列になる
  4. T04
    PowerShell のパイプで渡した日本語が ? になる（claude -p・python・git）
  5. T05
    PowerShell で python や claude の出力を変数に入れると文字化けする
  6. T06
    手で動かすと通る Python が、タスクスケジューラやリダイレクトのときだけ UnicodeEncodeError（cp932）で落ちる
  7. T07
    PYTHONIOENCODING を設定したのに、python -I だと効かない
  8. T08
    PowerShell 5.1 で日本語入りの .ps1（BOM なし UTF-8）が、構文エラーになるか文字化けして動く
  9. T09
    .cmd / .bat のコメントが、コマンドとして実行される
  10. T10
    powershell -Command の1行に書いた $変数 が、呼ぶ前に消える
  11. T11
    Get-ChildItem の -Include が効かず、全部のファイルが返る
  12. T12
    PowerShell の "..." に書いた Markdown のバッククォートで、文字が消えて改行が入る
  13. T13
    Windows の PowerShell で書き込み中のログが 0 バイトに見える
  14. T14
    claude -p --allowedTools の後ろに書いたプロンプトが飲み込まれる

Codex CLI（OpenAI）

  1. C01
    Codex CLI が PowerShell 5.1 でパイプに渡した日本語が ? になる（終了コード 0）
  2. C02
    Codex CLI が PowerShell 5.1 で読んだ UTF-8（BOM なし）の日本語が化ける（終了コード 0）
