H04

Python で書いた Claude Code の拒否フックが、日本語のフォルダでだけ書き込みを通す

症状

書き込みを全部拒否するフックを Python で書いた。英数字のフォルダでは止まるのに、名前が日本語のフォルダへの書き込みは通る。エラーも警告も出ない。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
$jp = [string][char]0x65E5 + [char]0x672C + [char]0x8A9E
$t = Join-Path $d $jp; New-Item -ItemType Directory $t -Force | Out-Null
$py = & python -c "import sys; print(sys.executable)" 2>$null | Select-Object -First 1
if (-not $py) { 'CANNOT CHECK (python not found, or only the Microsoft Store stub: install Python from python.org)' } else {
[IO.File]::WriteAllText("$d\deny_all.py", "import sys, json`nopen(r'MARK', 'w').close()`ndata = json.load(sys.stdin)`nprint(json.dumps({'hookSpecificOutput': {'hookEventName': 'PreToolUse', 'permissionDecision': 'deny', 'permissionDecisionReason': 'deny_all'}}))`n".Replace('MARK', "$d\called.txt"))
$hook = '\"' + ($py -replace '\\', '/') + '\" \"' + ($d -replace '\\', '/') + '/deny_all.py\"'
[IO.File]::WriteAllText("$d\s.json", '{"hooks":{"PreToolUse":[{"matcher":"Write|Edit","hooks":[{"type":"command","command":"HOOK"}]}]}}'.Replace('HOOK', $hook))
[IO.File]::WriteAllText("$d\prompt.md", "Use the Write tool once to create the file $t\written.txt with the content hi. Do not retry if it is blocked.", (New-Object Text.UTF8Encoding $false))
Push-Location $d
"Read the file $d\prompt.md and do exactly what it says." | claude -p --settings s.json --permission-mode acceptEdits --allowedTools "Read,Write" | Out-Null
Pop-Location
$w = Test-Path "$t\written.txt"; $c = Test-Path "$d\called.txt"
"deny-all Python hook, target folder with a Japanese name: hook called=$c, written=$w"
if (-not $c) { 'CANNOT CHECK (the hook was never called: check disableAllHooks or your settings)' } elseif ($w) { 'REPRODUCED' } else { 'NOT REPRODUCED' }
}

なぜ起きるか

Claude Code はフックの標準入力に UTF-8 の JSON を送る。日本語 Windows の Python は、標準入力が端末でないとき cp932 で読むので、json.load(sys.stdin) が日本語のパスで JSONDecodeError（Invalid \escape）になる。「語」の UTF-8 の最後のバイトが cp932 の2バイト文字の1バイト目と読まれ、後ろの \ を巻き込むため。フックが例外で落ちた終了コード 1 は「止めない失敗」なので、onFailure を付けていなければ書き込みは進む。

直し方

標準入力をバイト列のまま読んで UTF-8 で解く。あわせて "onFailure": "block" を付ける（直す前のフックのままでも、これで止まった）。拒否の理由は ASCII で出す（json.dumps の既定のまま）。

import sys, json
data = json.loads(sys.stdin.buffer.read().decode("utf-8"))

作者の PC での結果

同じ拒否フックで、英数字のフォルダは止まり、日本語のフォルダは書き込まれた。onFailure: block を足すと止まった（2026-10-24、Claude Code 2.1.310）

作者の PC: Windows 11 / Windows PowerShell 5.1.26100 / Python 3.13.7 / Claude Code 2.1.304、日本語の Windows（コードページ 932）。2026-10-20〜22 に確認。

ほかの症状

  • PowerShell の終了コードが、2 を返したのに 1 になる
  • -File で渡した2つ目の引数が、エラーなしで消える
  • -File で a,b と渡すと、配列にならず1つの文字列になる
  • パイプで渡した日本語が ? になる（claude -p・python・git）
  • python や claude の出力を変数に入れると文字化けする
  • 手で動かすと通る Python が、タスクスケジューラやリダイレクトのときだけ落ちる
  • PYTHONIOENCODING を設定したのに、python -I だと効かない
  • 日本語入りの .ps1 が、構文エラーになるか文字化けして動く
  • .cmd / .bat のコメントが、コマンドとして実行される
  • powershell -Command の1行に書いた $変数 が、呼ぶ前に消える
  • Get-ChildItem の -Include が効かず、全部のファイルが返る
  • "..." に書いた Markdown のバッククォートで、文字が消えて改行が入る
  • 書き込み中のログが 0 バイトに見える
  • claude -p --allowedTools の後ろに書いたプロンプトが飲み込まれる
  • Claude Code の PreToolUse フックが、時間切れになると書き込みを止めずに通す
  • PowerShell のフックを -Command で呼ぶと、Claude Code の拒否が素通りする
  • Claude Code のフックが1つも動かない（disableAllHooks が残っている）
