H09

Claude Code の Bash ツールで、$$( を含むコマンドが「削除の安全確認」で止まる

Claude Code can't rule out a dangerous removal · Claude Code Bash 止まる rm

症状

削除をしていないのに、Bash ツールの呼び出しが「危ない削除かもしれない」という確認で止まり、コマンドが動かない。コマンドの中に $$( という並び（ドル記号2つと丸括弧）がある。確認なしで動くモード（bypassPermissions）でも止まる。

30秒で確かめる

PowerShell（Windows PowerShell 5.1）に貼って実行します。一時フォルダ（%TEMP% の下）にだけファイルを作ります。最後に REPRODUCED と出たら、あなたの PC で起きています。 claude を1回呼ぶので、1分ほどかかります。

$d = Join-Path $env:TEMP ('cc-trap-' + (Get-Date -Format 'yyyyMMddHHmmss')); New-Item -ItemType Directory $d -Force | Out-Null
[IO.File]::WriteAllText("$d\p1.txt", 'Run exactly this Bash command and nothing else, then stop: echo ''a$$(b'' > x.txt')
[IO.File]::WriteAllText("$d\p2.txt", 'Run exactly this Bash command and nothing else, then stop: echo ''a$(b'' > y.txt')
Push-Location $d
Get-Content "$d\p2.txt" -Raw | claude -p --allowedTools Bash | Out-Null
Get-Content "$d\p1.txt" -Raw | claude -p --allowedTools Bash | Out-Null
Pop-Location
$y = Test-Path "$d\y.txt"; $x = Test-Path "$d\x.txt"
"echo with one dollar and a paren -> written=$y; echo with two dollars and a paren -> written=$x"
if (-not $y) { 'CANNOT CHECK (even the one-dollar command did not run: check that the Bash tool is available and allowed)' } elseif (-not $x) { 'REPRODUCED' } else { 'NOT REPRODUCED' }

なぜ起きるか

Claude Code は、Bash のコマンドを実行する前に、消しすぎる削除が無いかを調べる。$$( が入ると、シェルがどう読むかを Claude Code が確かめきれず、削除かもしれないとして止める（公式 issue #108970）。$( が1つだけなら通る。

直し方

$$( を含む本文は、コマンドに直接書かず、Write ツールでファイルに保存してから使う。どうしてもコマンドに書くなら、"a\$\$(b" のようにドル記号の前にバックスラッシュを置く。Claude Code 自身にこう書かせる CLAUDE.md の型は、本の9章（CLAUDE.md の型を読む（Zenn・全章 1,200円／0〜4章は無料） ）にある。

# Write ツールでファイルに保存してから使う
# どうしてもコマンドに書くなら
echo "a\$\$(b"
